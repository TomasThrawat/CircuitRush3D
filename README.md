# Circuit Rush 3D

Native Kotlin 3D racing game (OpenGL ES 3.0) - single player vs AI cars. No WebView / HTML.

* 9 open-wheel cars, modular circuit assembled from CC0 GLB pieces (3D Assets MCP pack `grand-prix-circuit-and-open-wheel`, CC0 1.0).
* Track layout, centerline and props are generated offline into `app/src/main/assets/track.json`.
* Arcade physics, AI opponents (Easy / Medium / Hard), lap timing, minimap, touch or tilt steering.

Build: GitHub Actions `build-apk.yml` -> artifact `CircuitRush3D-debug`.
